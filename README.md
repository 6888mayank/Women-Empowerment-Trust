## 🚀 Key Features

- **Pillars of Impact:** Custom vector SVG illustrations and detailed frameworks for:
  1. Women's Empowerment & Self-Help Groups (SHGs)
  2. Vocational Skill Development & Home-Based Candle Making
  3. Inclusive Rural Education & Adolescent Girls Support
  4. Preventive Healthcare, Sanitation & Clean Water
  5. Sustainable Agriculture & Recognition of Women Farmers
  6. Digital & Financial Inclusion (Jan Dhan, UPI & Direct Banking)
- **Interactive Financial Transparency:** Interactive SVG Donut and Horizontal Bar charts displaying verified program fund distribution.
- **CSR & Institutional Donor Hub:** Dedicated partnership framework with validated multi-step inquiry form and instant feedback.
- **Direct Outreach & Contact Hub:** Contact form with honeypot spam protection, direct WhatsApp connect, and live Google Maps integration for Mahasamund.
- **Mobile First & High Accessibility:** Fully responsive design with sticky navigation, accessible modals, and micro-animations.

## 📦 Getting Started

### 1. Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/6888mayank/Women-Empowerment-Trust.git

# Navigate into project directory
cd Women-Empowerment-Trust

# Install dependencies
npm install
```

### 3. Development Server
```bash
npm run dev
```
Visit `http://localhost:5173` in your browser.

### 4. Production Build
```bash
npm run build
```
Generates production assets in the `dist/` directory.
